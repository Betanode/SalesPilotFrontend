# 🎯 Sales AI Coach Frontend

A modern UI for interacting with the AI Sales Coach — built to simulate real-time coaching conversations.

---

## 🧠 Overview

Frontend allows users to:

* Chat with AI sales coach
* Answer questions step-by-step
* Receive structured feedback
* Practice real-world sales scenarios

---

## ⚙️ Tech Stack

* **React (Vite)**
* **TypeScript**
* **Tailwind CSS**
* **Modern UI components**

---

## 🔥 Features

* 💬 Chat-based interaction
* ⚡ Fast UI (Vite)
* 🎨 Clean and responsive design
* 🔄 Real-time conversation flow
* 📊 Feedback-driven UX

## 🚀 Getting Started

### 1. Clone repo

```
git clone https://github.com/<your-username>/SalesPilotFrontend.git
cd SalesPilotFrontend
```

---

### 2. Install dependencies

```
npm install
```

---

### 3. Run app

```
npm run dev
```

---

## 🔌 Backend Integration

Frontend connects to FastAPI backend:

```
POST /start-session
POST /chat
POST /upload
```
